# VirtualOpenHouse

## Documentation

Basic info on how Jekyll works is available in [the PDF](docs/Jekyll%20School%20Project%20Tutorial.pdf). In addition to basic layouts and includes, our project also uses a [plugin](_plugins/courses.rb) to load `_courses` and create multiple pages per course.

### Information

The [Drive folder](https://drive.google.com/drive/folders/10giAfNwJrXs2nSNa1ZI3tbvEbMmxpP0s) contains the Google Sheet, credentials, images, etc.

### Jekyll Environment setup

Jekyll requires Ruby to be installed to build the template files and serve the webpage.

[SETUP.md](docs/SETUP.md)

### API Server setup

The API pulls information automatically from a Google Sheet using a Python Flask server. It is also pushed to automatically when the Sheet is updated through an NGrok tunnel.

[API_SETUP.md](docs/API_SETUP.md)

[run.sh](run.sh) runs both the API and serves the Jekyll website
